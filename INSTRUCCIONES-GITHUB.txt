ALAYA - Archivos listos para GitHub Pages

1. Descomprime este ZIP.
2. En GitHub, abre tu repositorio de ALAYA.
3. Elimina o reemplaza los archivos anteriores que correspondan.
4. Sube TODOS los archivos de esta carpeta a la RAIZ del repositorio (donde esta index.html). NO subas la carpeta contenedora.
5. Confirma los cambios (Commit changes).
6. Espera a que GitHub Pages publique y recarga con Ctrl + Shift + R.

Las imagenes y los archivos HTML, CSS y JS estan todos juntos; sus rutas ya estan ajustadas.
